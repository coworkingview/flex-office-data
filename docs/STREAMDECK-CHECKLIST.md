# Stream Deck Marketplace checklist

Reviewed against the Stream Deck SDK and Marketplace guidelines on 1 Nov 2026. `streamdeck validate` is the mechanical check; a person still submits in Maker Console.

Models for a small, recently accepted plugin that shows remote data on a key:

- [My Tempest](https://marketplace.elgato.com/product/my-tempest-0265c0ce-1dd2-41bf-96d7-002fb0a72b93) — Cath Ellis, 27 Oct 2026. One plugin, several readout actions, press opens a page, Stream Deck 6.9+, free, support address on the listing.
- [PowerCost](https://marketplace.elgato.com/product/powercost-e9ac8303-7ba0-4b67-8760-c153213c9b0e) — Dloper, 1 Oct 2026. Live figure on a key, property inspector, SDK 3, free listing text that states requirements.
- [Fetcher: JSON & HTML Monitor](https://marketplace.elgato.com/product/fetcher-json-html-monitor-6b6b7390-d39c-44c0-aff6-427c249e2623) — 2kit, 21 Sep 2026. Public HTTP JSON onto a key, cached polling, placeholder when data is missing, MIT, macOS 12 and Windows 10.

## Plugin metadata

| Rule | How this plugin satisfies it | Source | Rejection risk |

| Category is set and matches the plugin name. No author name in the category. | Category `Coworking Prices`. | [Plugin guidelines — Naming](https://docs.elgato.com/guidelines/stream-deck/plugins) | Leaving the category empty files the actions under Custom. |

| OS minimums are real. | macOS 12, Windows 10, same floor as the current SDK samples and as Fetcher. | [Manifest — OS](https://docs.elgato.com/streamdeck/sdk/references/manifest) | Claiming an older macOS than the build was tried on. Nobody has run this build on a device yet. |

## Behavior and property inspector

| Rule | How this plugin satisfies it | Source | Rejection risk |
| --- | --- | --- | --- |
| Single-select settings use a select. Settings save on change. No Save button. No donation link. | City and figure are `<sdpi-select setting="...">`. The website control only opens the site. `sdpi-components.js` v4 is vendored. | [Plugin guidelines — Property inspectors](https://docs.elgato.com/guidelines/stream-deck/plugins) | A Save button, or a Ko-fi link in the inspector. |
| Separate inspectors so unused controls are absent. | `ui/workspace-count.html` has city. `ui/market-rate.html` has city and figure. | [Plugin guidelines — Property inspectors](https://docs.elgato.com/guidelines/stream-deck/plugins) | One shared file that shows the figure select on Workspace Count. |
| City list comes from data the API published. | `sendToPropertyInspector` returns `{ event: "getCities", items }` from `GET /v1/market/rates?locale=en`. If that call fails, the only option is Berlin, which is a real city. | [Settings](https://docs.elgato.com/streamdeck/sdk/guides/settings), [Property inspector events](https://docs.elgato.com/streamdeck/sdk/references/websocket/ui) | Inventing cities. |
| Failure uses `showAlert`. Success is the new title, so there is no `showOk`. | `showUnavailable` sets the title to an em dash and alerts when the user just opened the key or changed settings. The 30 minute refresh logs the error and does not alert on every tick. | [Plugin guidelines — Temporary feedback](https://docs.elgato.com/guidelines/stream-deck/plugins) | Alerting every half hour while the API is down. |
| User titles stay off so the live title is not overwritten by a custom label. | `UserTitleEnabled` is false. Keypad only. | [Manifest — Actions](https://docs.elgato.com/streamdeck/sdk/references/manifest) | Letting a custom title hide the number the action exists to show. |
| Press opens the canonical site. | `streamDeck.system.openUrl("https://coworkingview.com")`. | Product request, and the support link in the listing. | Opening `https://www.coworkingview.com`. |
| Only real response fields are shown. | Inspected `GET /v1/market/rates` and `GET /v1/properties` on 1 Nov 2026. `locale` is required. Count is `meta.pagination.total` (Berlin was 143). Rate is `median.amount` and `median.currency` (Berlin flex desk median was 214 EUR on `asOf` `2026-10-30T13:21:31.959Z`). Amounts are not re-rounded. `data.propertyCount` on the rates index is a different number and is not displayed. Tests read `integrations/streamdeck/fixtures/`. | Live API `https://api.coworkingview.com`. [Plugin guidelines](https://docs.elgato.com/guidelines/stream-deck/plugins) | Showing the index `propertyCount`, a sample size, or a made-up average as the workspace count. |
| Refresh is infrequent. | 30 minutes (`REFRESH_INTERVAL_MS`). The API cache headers are shorter (about 5–10 minutes). One retry on HTTP 429 or 5xx, capped at 10 seconds. Timeout 20 seconds. User-Agent `coworkingview-streamdeck/1.0.0`. | [Fetcher listing](https://marketplace.elgato.com/product/fetcher-json-html-monitor-6b6b7390-d39c-44c0-aff6-427c249e2623) polls and caches. Rate limit on the public API is 120 requests per 60 seconds. | Polling every few seconds from many keys. |
| No operator catalogue content. | The properties request uses `pageSize=1` and the parser keeps total, city name, and citation text. Titles, excerpts, and images are dropped. | Repository data rules for the public catalogue. | Rendering a listing photo or description on the key. |
| CC BY 4.0 attribution stays with the rates. | `data.attribution` is logged on every fresh rates response. The listing states the license. | Rates payload `license` / `licenseUrl` / `attribution`. | Stripping the attribution string. |

## What a person still has to do

1. Create or sign in to an Elgato account and open [Maker Console](https://maker.elgato.com). The publishing steps are in [Distribution](https://docs.elgato.com/streamdeck/sdk/introduction/distribution).
2. Create the organization **CoworkingView** so it matches `Author`, and accept the Maker Agreement under organization settings.
3. Search Marketplace for "Coworking Prices". If that name is taken, stop and pick another name before upload. UUIDs in this repository would then need a matching change before the first publish, not after.
4. Download `com.coworkingview.prices.streamDeckPlugin` from the CI artifact on this pull request. `streamdeck pack` names the file from the UUID.
5. Upload it. Leave "Publish after review" off if you want the DRM-processed build from the Versions tab to install on a device first.
6. Paste the name, description, release notes, price Free, and links from `docs/STREAMDECK-LISTING.md`.
7. Upload `integrations/streamdeck/marketplace/app-icon-288.png`.
8. Capture the thumbnail and three gallery images on a Mac or Windows PC with Stream Deck 7.1 or later. Install the packed plugin, put both actions on a device, and screenshot the action list, the Market Rate inspector, and the live keys.
9. Declare AI assistance.
10. Choose Monitoring and Utilities if those tags are on the form.
11. On hardware, confirm Berlin shows a catalogue total and a flex-desk median, changing city updates both keys, an unknown figure shows an em dash and an alert, and a press opens https://coworkingview.com.
