# Changelog

## 0.1.0

First release of `@coworkingview/backstage-plugin-coworkingview`.

- Page and card for one city's Price Index medians and a single page of spaces.
- `coworkingview.defaultCity` in app-config, with an optional `coworkingview.baseUrl` for the Backstage proxy.
- Legacy `createPlugin` entry point and a new frontend system plugin at `@coworkingview/backstage-plugin-coworkingview/alpha`.
