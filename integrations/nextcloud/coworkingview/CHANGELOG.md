# Changelog

## 1.0.0

- Dashboard widget to search flexible workspaces by city and workspace type.
- Unified Search for a workspace name, or for the workspaces in a city. It stays off until search of connected services is enabled.
- Each result shows the name, the city, the workspace type and a link to the listing on coworkingview.com.
- Prices, photos and descriptions are not stored.
