# Changelog

## 1.0.0

First release of CoworkingView Workspace Prices (`mod_coworkingview`).

The module shows indicative flexible-workspace prices for one city from `GET /v1/market/rates` on `https://api.coworkingview.com`. Parameters are the city, the product type, the language, how many rows to show, and how long to cache a successful response.

The installable zip is attached to the GitHub release tagged `joomla-v1.0.0` after this branch is merged. That release is what the update stream downloads. See [README.md](README.md).
