# Security policy

The packages are read-only clients of a public, keyless API: they store no
credentials and write nothing except the files you ask the CLI to output.

To report a vulnerability in this repository or in api.coworkingview.com,
email **info@coworkingview.com** with "security" in the subject. Please don't
open a public issue for it. We aim to answer within five working days.

Supported versions: the latest release of each package.
